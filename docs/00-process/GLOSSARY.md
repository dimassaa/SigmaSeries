# GLOSSARY — термины проекта

> v0.1 · Фаза 4 · закрывает разнобой терминов из `PLAN` §1, п. 7. **Читает `context-pack.mjs`:** термин попадает в пакет фичи, если его название встречается в тексте. Поэтому определения короткие, а синонимы перечислены явно — иначе одно и то же будет называться двумя словами.
> Требование Бланка 3.5: подписи на схемах и в интерфейсе — на русском или белорусском языке. Этот глоссарий — тот самый «словарь RU первым», на который ссылаются `PLAN` C-10 и `M2-catalog` F-02-11.

## Термины предметной области

| Термин | Синонимы в проекте | Значение |
|---|---|---|
| Сериал | тайтл, шоу, сериал | Произведение целиком: объект каталога верхнего уровня. То, что в TMDB помечено `tvSeries` или `tvMiniSeries` |
| Сезон | сезон | Группа серий внутри сериала. Сезон 0 — спецвыпуски, вне прогресса и отметок «всё вышедшее» (H-38) |
| Серия | эпизод, серия | Одна серия сезона с номером и, возможно, датой выхода. В IMDB — `episode` |
| Выход | событие выхода, релиз | Дата выхода серии **или группы серий с одной датой**. Если сезон вышел целиком за один день, это один выход, а не двадцать |
| Точность даты | — | `exact` (есть время) или `date` (только дата, обычный случай для стримингов) |
| Состояние выхода | статус сериала | Производная величина: Анонс, Выходит, Ждём сезон, Завершён, Отменён. Источник истины — даты выходов, а не статус TMDB |
| Выходит | — | Есть выход в окне от −14 дней и дальше. Только такие сериалы попадают в календарь и в «Новинку дня» |
| Ждём сезон | — | Статус Returning Series, но дат нет. Не дефект данных: так у 143 из 1191 сериалов каталога |
| Постер | обложка, кадр постера | Вертикальная картинка 2:3. Основная карточка в каталоге |
| Фон | бэкдроп, фоновая | Горизонтальная картинка 16:9 для шапки страницы сериала и баннеров |
| Фокусная точка | точка кадрирования | Точка изображения, которая остаётся видимой при обрезке под разные пропорции. Задаётся админом, по умолчанию 2/3, 1/3 |
| Фокальная точка экрана | главный элемент | Один главный объект внимания на экране. Не путать с фокусной точкой изображения — термин перегружен, в UI это `hero` |

## Термины пользовательского поведения

| Термин | Синонимы в проекте | Значение |
|---|---|---|
| Статус просмотра | статус | Где человек с сериалом: Смотрю, В планах, Просмотрено, Брошено, Отложено. Одно значение на пару «пользователь — сериал» |
| Отметка просмотра | отметка, галочка | Факт «я посмотрел серию». Бывает точная (по факту) и ретро (отметил задним числом). Из них прогресс и итоги считаются **только по точным** |
| Ретро-отметка | — | Отметка серии задним числом после «отметить всё». Исключается из «любимого времени суток» в итогах |
| Закладка | избранное | То, что человек сохранил для себя. Не то же, что статус: можно иметь закладку без статуса |
| Библиотека | мои сериалы | Раздел со всем, у чего есть статус или отметки. Не то же, что закладки |
| Подписка на выходы | уведомления о выходах | Автоматическая или ручная подписка на уведомление о дате выхода серии |
| Тихые часы | — | Период, в который уведомления не доставляются. Создание уведомления при этом не отменяется |
| Итоги | Wrapped, итоги года | Персональная сводка за период: что смотрел, когда, сколько, любимый сериал. Основа — точные отметки |
| Рекомендации | «Для вас», похожие | Два разных механизма: персональные (M11) и «похожие к этому сериалу» (M2 F-02-08). Не смешивать в одном списке |
| Спойлер | раскрытие спойлера | Метка автора: текст раскрывает то, что ещё не выходило. Влияет на отображение, не на хранение |
| UGC | пользовательский контент | Четыре вида: отзыв, комментарий, руководство, обсуждение. `input/spec.md` говорит только про обсуждения, границы всех четырёх задаёт M5 |
| Руководство | гайд, статья | Пользовательская статья по сериалу с разделами и спойлер-меткой. Не путать с руководством пользователя из Бланка (это документ курсового) |

## Термины модерации и администрирования

| Термин | Синонимы в проекте | Значение |
|---|---|---|
| Проверка | модерация, фильтр | Поиск по словарю в тексте материала. Без машинного обучения, работает с русским и английским |
| Помечен | подозрительный, на проверке | Материал с найденным словом не публикуется, ждёт решения редактора |
| Одобрить | разрешить | Решение редактора: материал публикуется. Попавшее слово можно добавить в белый список |
| Запретить | отклонить, удалить | Решение редактора: материал не публикуется, автор получает причину |
| Кластер модерации | группа дублей | Несколько похожих материалов, объединённых в одну очередь, чтобы редактор не принимал решение N раз подряд |
| Мьют | временный запрет | Временная блокировка отправки материалов. Не бан: вход и чтение продолжают работать |
| Бан | блокировка | Полная блокировка аккаунта с отзывом сессий. Материалы при бане можно скрыть флажком в диалоге (Q-18, DEC-020) |
| Анонимизация | обезличивание | Очистка личных данных с сохранением записи и её материалов. Не то же, что удаление |
| Аудит | журнал действий | Только чтение, кто что сделал и когда. Не редактируется и не удаляется |
| Карточка неполная | неполная позиция | Сериал ниже порога полноты (`CONTENT-PLAN` §3). Попадает в очередь админа |
| Полнота карточки | — | Процент заполненных обязательных полей. Три уровня: Минимум, Пригодна к показу, Полная |

## Термины процесса

| Термин | Значение |
|---|---|
| Фича | Одна спецификация `F-xx-xx` внутри модуля, описывается по 20 измерениям (`PLAN` §5) |
| Измерение | Один из 20 аспектов описания фичи. Измерения 11–16 описываются таблицей модуля, а не внутри фичи |
| Модуль | `M0…M12`, единица разделения спецификации |
| Экран | `S-xx`, адрес в `SCREENS`. Компонент оболочки — `UI-xx`, адреса не имеет |
| Операция | `OP-xx`, бизнес-операция сверх CRUD. Бланк требует не менее 10; у нас 17 |
| Правило | `R-DES/SEC/SEO/PERF/I18N/A11Y/AN/MOD/TST-NN`, проверяемое утверждение в стандарте |
| Граничный случай | `EC-xx`, ситуация, выходящая за обычный ход. Реестр собирается скриптом |
| Гипотеза | `H-xx`, решение, принятое по умолчанию без вопроса автору. Снимается, когда автор подтверждает |
| Решение | `DEC-xx`, выбор, подтверждённый автором |
| Спайк | Замер на реальных данных, чтобы не гадать. Два прогона выполнены, скрипт утрачен |
| Заморозка P0 | Момент, после которого спецификацию P0 не меняют, чтобы код не разъехался с документами |

## Запрещённые сокращения

`Гайд` = руководство пользователя по сериалу (UGC), а не документ курсового. `Трей` = одна серия, а не серия-как-сериал-целиком. `Онлайн» = число активных за последние 15 минут (операция OP-14), а не «сколько сейчас в сети» в общем смысле. `Правка` = изменение админом карточки вручную, в отличие от данных, пришедших из импорта.

## F-02-01 Страница сериала (S-06) · P0

1. **Назначение.** Дать полную картину сериала и точку входа в действия (статус, оценка, отзывы).
2. **Роли.** Все; кнопки статуса и оценки — для зрителя (гостю — «Войдите, чтобы отметить» с возвратом на то же место, `R-SEC-08`).
3. **Триггер.** Переход по `/{locale}/series/{slug}`.
4. **Сценарий.** Шапка (фон, название, годы, возраст, состояние выхода, жанры, страны и канал, три рейтинга, действия) → якорное меню → «Обзор» (описание с «Читать далее», факты) → «Серии» (переключатель сезонов, список серий с датами) → «В ролях» (до 10, «Показать всех») → «Отзывы» (гистограмма, лучшие 3, «Все отзывы» → S-09) → «Обсуждения» и «Руководства» (P1; блоки скрыты, пока M5 их не отдаёт) → «Похожие» (6 постеров, F-02-08).
5. **Альтернативы и ошибки.** Неизвестный адрес → 404; сериал в архиве → 410 со страницей «Сериал снят с публикации» и «похожими»; старый `slug` → 301; EN без перевода описания → страница есть, индексируется как `noindex` (`R-SEO-04`).
6. **Состояния.** Загрузка: скелет шапки с зарезервированной высотой (пропорция 16:9 на десктопе, 4:5 на телефоне) и секций · Пусто: нет отзывов — «Пока нет отзывов. Отметьте серию и станьте первым» · «Ждём сезон» — плашка «Ждём новый сезон» вместо следующей серии, кнопка «Сообщить, когда объявят дату» (P1, H-26) · Нет данных об отдельных блоках — блок скрывается (`CONTENT-PLAN` §4) · Ошибка — страница 500 (S-43) · Нет прав — не применимо · Офлайн — страница офлайна.
7. **Данные.** См. §0; ранги и голоса — только в служебных экранах.
8. **Правила.**
   - **Состояние выхода** выводится рядом с названием: «Выходит · следующая серия {дата}» / «Ждём новый сезон» / «Завершён» / «Отменён» / «Анонс». Для сезона целиком — «вышли все N серий {дата}».
   - **Возраст** — по H-25 (RU → BY → другая страна с пометкой «по данным США» → не показываем).
   - **Рейтинги:** показываем IMDb, TMDB, сайт (M4), затем платформы из справочника по порядку; формат `8,7 / 10`; число голосов сокращённо («2,7 млн»); «Нет оценок», если данных нет; у TMDB при голосах < `rating.min_votes_display` — «Мало оценок»; значение цветом не кодируется.
   - **Скрытие описаний** непросмотренных серий — настройка пользователя (H-37; по умолчанию показываем).
   - **Сезон 0** («спецвыпуски») свернут, в прогресс не входит (H-38).
   - Когда у сериала больше 8 сезонов, переключатель сезонов — прокручиваемая строка + «Все сезоны» (список).
9. **Валидация и лимиты.** Параметры маршрута проверяются (`slug` — латиница, цифры, дефис).
10. **Edge cases.** EC-C1, EC-C2, EC-C13, EC-C14, EC-K1, EC-K2.
17. **Побочные эффекты.** EV-06 `series_view`; кэш страницы сбрасывается при обновлении сериала.
18. **Приёмка.** *Дано* сериал «Выходит» с датой следующей серии; *когда* гость открывает страницу; *тогда* в HTML есть название, описание, рейтинги, график и JSON-LD `TVSeries`; в шапке видна дата следующей серии. *Дано* сериал в архиве; *тогда* ответ 410. *Дано* нет постера; *тогда* показана плашка с названием и годом, CLS = 0. *Дано* смена `slug`; *тогда* старый адрес отвечает 301.
19. **UI.** Десктоп (≥ 1280, правой панели нет):

```
┌rail┬────────────────────────────────────────────────────────────┐
│    │ ШАПКА: фон 16:9, фокус кадра справа-сверху (2/3, 1/3)      │
│    │ ┌ стекло, левая треть ─────────┐                           │
│    │ │ Название (h1)                │          (объект кадра    │
│    │ │ Оригинал · 2008–2013 · 16+   │           вне плашки)     │
│    │ │ Выходит · след. серия 12 окт │                           │
│    │ │ IMDb 9,5   TMDB 8,9   Сайт 9,1│  ← три крупных числа     │
│    │ │ [Смотрю ▾]  [Оценить]        │                           │
│    │ └──────────────────────────────┘                           │
│    │ Обзор · Серии · В ролях · Отзывы · Похожие   (липкое меню) │
│    │ Описание … Читать далее        │ факты: страны, канал, жанры│
│    │ Серии: [Сезон 1][2][3]… список с датами и отметками        │
│    │ В ролях · Отзывы · Похожие (6 постеров)                    │
└────┴────────────────────────────────────────────────────────────┘
```
   **Фокальная точка:** плашка с названием и тремя рейтингами в левой трети шапки; главное действие — «Смотрю» (один primary, `R-DES-06`); крупных чисел три. Стекло — только плашка над изображением. **Телефон (< 640):** фон 4:5 с фокусом, плашка под изображением без стекла, действия во всю ширину, меню — прокручиваемая строка; **планшет (640–1024):** плашка поверх, рейтинги в строку. **Скелетон:** блок шапки (aspect-ratio), 3 строки плашки, полоса меню, 6 карточек «Похожих».
20. **КП.** Диаграмма вариантов использования; скриншот на плакат.

## F-02-02 Сезон и серия (S-07, S-08) · P0

1. **Назначение.** Работа на уровне сезонов и серий: даты, описания, отметки, оценки.
2. **Роли.** Все; отметки и оценки — зритель (M3, M4).
3. **Сценарий.** S-07: заголовок «{Сериал}, сезон N», список серий (номер, название, описание кратко, дата или «сегодня / завтра / через N дней», длительность, место для отметки и оценки); для сезонов целиком — группа «Все N серий вышли {дата}». S-08: название, «Сезон N · Серия M», дата, описание, предыдущая / следующая, место оценки, место комментариев (M5).
4. **Альтернативы и ошибки.** Нет серии с таким номером — 404; серия без даты — «Дата уточняется»; нет названия — «Серия N».
5. **Состояния.** Загрузка (строки списка фиксированной высоты) · пусто (сезон без серий — «График уточняется») · ошибка.
6. **Правила.** Не вышедшая серия не отмечается (M3); описание серии скрывается по H-37; подписи дат — единый компонент `R-I18N-05`; **S-08 индексируется только если есть описание и дата ≤ сегодня** (тонкие страницы — `noindex, follow`, H-35).
7. **Edge cases.** EC-K3, EC-K4.
8. **Приёмка.** *Дано* сезон с 8 сериями одной датой; *когда* открыта S-07; *тогда* показана одна группа «Все 8 серий вышли {дата}» и 8 отдельных строк. *Дано* серия без описания; *тогда* S-08 `noindex, follow`.
9. **UI.** Список — одна колонка, строка = номер · название · дата справа; фокус — название серии; даты и длительность моноширинными цифрами. Телефон — то же, дата под названием.
10. **КП.** Диаграмма классов (Сериал–Сезон–Серия).

**Остальные измерения шаблона.**
- **Триггер.** Переход по адресам сезона и серии; ссылки из списка серий и «следующая серия».
- **Данные.** E-Season, E-Episode, выходы (M12), описания ru / en; прогресс и оценки — из M3 и M4.
- **Валидация и лимиты.** Номера сезона и серии — целые (сезон ≥ 0, серия ≥ 1); неверный адрес — 404.
- **Побочные эффекты.** `page_view` (EV-01); отметка — в M3.

## F-02-03 Каталог с фильтрами (S-02) · P0

1. **Назначение.** Найти сериал по признакам.
2. **Роли.** Все.
3. **Сценарий.** Фильтры: жанры (несколько), годы (диапазон-ползунок), рейтинг IMDb от (ползунок), страна (несколько, с поиском), состояние выхода, канал или платформа (несколько, с поиском); сортировка: популярность (по голосам IMDb, по умолчанию), рейтинг, новизна (дата первой серии), название; сетка постеров (6 в ряд на десктопе); под постером — название, год, страна, один жанр (как в spec); постраничность по `catalog.page_size`.
4. **Альтернативы и ошибки.** Недопустимое значение в адресе — игнорируется и показывается базовый список; пусто — «Ничего не найдено по этим фильтрам» + «Сбросить» + предложение убрать последний фильтр.
5. **Состояния.** Загрузка: 24 скелета карточек той же высоты · пусто · ошибка · частично (у части нет постера — плашки).
6. **Правила.** Состояние фильтров полностью в адресе (`?genre=drama&year=2015-2020&sort=rating&page=2`), ссылкой можно поделиться; **постраничность — настоящие ссылки** (`R-SEO-09`); канонический адрес — базовый список (`R-SEO-02`); при пустой выдаче `noindex`. Фильтры применяются без перезагрузки как улучшение, при отключённых скриптах работают обычными ссылками и формой.
7. **Валидация.** Диапазоны ограничены данными (минимум и максимум берутся из каталога); список значений — белый список (`R-SEC-16`); `page` ≥ 1, `limit` не принимается от клиента.
8. **Edge cases.** EC-K5, EC-K6.
9. **Приёмка.** *Дано* фильтр «Драма» и годы 2015–2020; *когда* открыт адрес; *тогда* в выдаче только такие сериалы, число результатов указано, постраничность — ссылки. *Дано* нет результатов; *тогда* страница `noindex` и кнопка «Сбросить». p95 ответа ≤ 300 мс.
10. **UI.**

```
┌rail┬ Фильтры (колонка 240)  ┬ Сортировка ▾      результатов: N  ┬ панель ┐
│    │ Жанры  ☐ Драма …      │ ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐            │ скоро  │
│    │ Годы   ──●────●──     │ │П ││П ││П ││П ││П ││П │ 6 в ряд    │ (от    │
│    │ Рейтинг от ──●──      │ └──┘└──┘└──┘└──┘└──┘└──┘            │ 1280)  │
│    │ Страна, канал, статус │ названия · год · страна · жанр      │        │
│    │                       │ « 1 2 3 … 12 »  (ссылки)            │        │
└────┴───────────────────────┴─────────────────────────────────────┴────────┘
```
    **Фокус:** сетка постеров (центр и вторая–третья трети). Фильтры — слева, не конкурируют. **Телефон:** фильтры в нижней выдвижной панели («Фильтры · 3»), сетка 2 в ряд; **планшет:** 3 в ряд. Выдвижная панель — стекло допустимо (`R-DES-21`).
11. **КП.** Диаграмма деятельности «Поиск и фильтрация».

**Остальные измерения шаблона.**
- **Триггер.** Переход в «Каталог» из меню; изменение фильтра, сортировки, страницы.
- **Данные.** Опубликованные сериалы, жанры, страны, каналы, рейтинг IMDb, голоса (для сортировки), дата первой серии.
- **Побочные эффекты.** `page_view` (EV-01); состояния на сервере нет — всё в адресе.

## F-02-04 Жанры (S-03, меню UI-03) · P0

1. **Назначение.** Навигация по жанрам.
2. **Сценарий.** Меню «Сериалы» показывает жанры (мега-меню на десктопе по наведению и фокусу; на touch — по нажатию; на телефоне — экран выбора жанра). Страница жанра: название, описание жанра (ru/en из справочника), сетка как в F-02-03 с предустановленным жанром, сортировка. Жанры в меню — из справочника с флагом «показывать» и числом сериалов ≥ 1.
3. **Правила.** Меню отдаёт жанры с числом сериалов; при **< 6 сериалов страница `noindex`** (таблица `SEO`); на главной блок жанра показывается только при ≥ 6 сериалах в запасном окне (EC-C7).
4. **Приёмка.** *Дано* жанр «Мюзикл» с 3 сериалами; *когда* открыта его страница; *тогда* она доступна, но `noindex`, в блоках главной не участвует.
5. **UI.** Мега-меню: колонки жанров по алфавиту ru/en, поиск по жанрам не нужен (20 штук); закрывается Esc, стрелки двигаются по пунктам (`R-A11Y-05`). Стекло — выпадающее меню над контентом.
6. **Edge cases.** EC-K7.

**Остальные измерения шаблона.**
- **Роли.** Все.
- **Триггер.** Наведение, фокус или нажатие на «Сериалы» в меню; переход по адресу жанра.
- **Альтернативы и ошибки.** Неизвестный или скрытый жанр — 404.
- **Состояния.** Мега-меню: загрузка (скелет колонок), нет жанров — раздел меню скрыт; страница жанра — как S-02.
- **Данные.** E-Genre (названия ru / en, описание, порядок, видимость), число сериалов по жанру.
- **Валидация и лимиты.** `slug` — латиница, цифры, дефис; в меню до 30 жанров.
- **Побочные эффекты.** `page_view` (EV-01).
- **КП.** Диаграмма классов (жанр–сериал); скриншот меню.

## F-02-05 Подборки: страницы (S-05, S-04) · P0 (S-04 — P1; правила OP-18 — P1)

1. **Назначение.** Тематические наборы, шире жанров.
2. **Сценарий.** S-05: баннер 16:9 с фокусом, название, описание, сериалы в порядке админа (сетка). S-04 (P1): сетка подборок с баннерами. Подборки создаёт админ (F-10-07).
3. **Правила.** Подборка видима, если опубликована и в ней ≥ 6 видимых сериалов (EC-C6; архивные не считаются); баннер по умолчанию — фон первого сериала, админ может заменить; на главной в бегущей строке — 6 подборок, **порядок задаёт админ (вес), позже — по просмотрам за 30 дней с закреплением (H-31, P1)**. Подборки по правилам (жанр, годы, страна, ключевое слово, минимальный рейтинг) — OP-18, P1, пересчёт ежедневно.
4. **Состояния.** Скелет баннера и сетки · подборка не найдена / не опубликована — 404.
5. **Приёмка.** *Дано* подборка из 5 видимых сериалов; *тогда* на главной и в S-04 её нет, в S-05 по прямой ссылке — 404. *Дано* в опубликованной подборке сериал ушёл в архив, осталось 5; *тогда* подборка скрыта автоматически.
6. **UI.** Баннер — фокальная точка по правилу третей, название слева.
7. **Edge cases.** EC-C6, EC-K8.

**Остальные измерения шаблона.**
- **Роли.** Все читают; создаёт и правит админ (F-10-07).
- **Триггер.** Нажатие на подборку в бегущей строке главной; адрес подборки; S-04 из меню.
- **Альтернативы и ошибки.** Подборка не опубликована или скрыта — 404.
- **Данные.** E-Collection, E-CollectionItem; правила — E-CollectionRule (P1).
- **Валидация и лимиты.** До 100 сериалов в подборке; `slug` — латиница, цифры, дефис.
- **Побочные эффекты.** `page_view` (EV-01); счётчик просмотров подборки — для автопорядка (P1).
- **КП.** Диаграмма классов; операция OP-18 (P1).

## F-02-06 Поиск (UI-09, S-17) · P0

1. **Назначение.** Быстро найти сериал, человека или подборку (H-12: пользователей не ищем).
2. **Сценарий.** Поле в верхней панели; плейсхолдер-подсказка («Название, актёр или подборка»); после `search.suggest_min_chars` знаков и паузы `search.suggest_debounce_ms` — подсказки (до `search.suggest_max`, сгруппированы: Сериалы · Люди · Подборки); Enter или кнопка → S-17 с результатами по группам; навигация стрелками, Esc закрывает.
3. **Правила нормализации и порядок.** Регистр, `ё → е`, пунктуация, диакритика (NFKD для латиницы), русская морфология через основу слова; **исправление раскладки** («ghbdtn» → «привет»): если исходный запрос ничего не дал, а исправленный — дал, показываем результаты по исправленному с пометкой и ссылкой «искать как было введено». Порядок: точное совпадение названия → начало названия → начало слова → опечатка (1 правка для слов от 5 знаков) → остальное; при равенстве — по голосам IMDb. Ищется по названиям ru, en, оригиналу; по людям (актёры, режиссёры); по названиям подборок.
4. **Требования к реализации.** Без внешних сервисов; индекс обновляется после каждого импорта и правки админа; подсказки p95 ≤ 100 мс на ≈ 1250 сериалах и ≈ 10 000 людях **[проверить в Фазе 7]**.
5. **Альтернативы и ошибки.** Пустой запрос — подсказки не показываются, S-17 с предложением популярного; запрос > 100 знаков — обрезается; ничего не найдено — «Ничего не найдено» + подсказки: проверьте раскладку, популярные жанры.
6. **Состояния.** Скелет подсказок (строки) · пусто · ошибка · офлайн («Нет связи»).
7. **Безопасность и приватность.** Запросы экранируются; лимит частоты (`R-SEC-31`, класс «поиск»); текст запроса не пишется в события — только по `R-AN-19` (агрегат «без результата», ≤ 60 знаков, без пользователя, 30 дней).
8. **a11y.** Шаблон комбобокса: `role="combobox"`, `aria-expanded`, `aria-activedescendant`, число найденных объявляется (`role="status"`).
9. **Приёмка.** *Дано* «Игра престолов» и «game of thrones»; *когда* ввод любого из них; *тогда* найден тот же сериал. *Дано* ввод «ghbdtn»; *тогда* результаты для «привет» с пометкой. *Дано* 1 символ; *тогда* подсказок нет. Подсказки p95 ≤ 100 мс.
10. **UI.** Подсказки — выпадающий слой под полем (стекло допустимо); результаты: группы с заголовками, сериалы — постер-карточки, люди — строки, подборки — строки с баннером. **Фокус:** поле запроса и первая группа результатов.
11. **Edge cases.** EC-K9, EC-K10.
12. **КП.** Диаграмма последовательности «Поиск»; алгоритм нормализации — в ПЗ 4.2.4.

**Остальные измерения шаблона.**
- **Роли.** Все.
- **Триггер.** Ввод в поле поиска; Enter; переход на S-17.
- **Данные.** Индекс названий (ru, en, оригинал), людей и подборок; при равенстве — голоса IMDb.
- **Валидация и лимиты.** Запрос ≤ 100 знаков; лимит частоты класса «поиск» (`R-SEC-31`); подсказок не больше `search.suggest_max`.
- **Побочные эффекты.** EV-05 (без текста запроса); агрегат «без результата» по `R-AN-19`.

## F-02-07 Подробная карточка постера (UI-10) · P0

1. **Назначение.** Показать суть сериала, не уходя со списка (spec: при наведении подробная информация).
2. **Триггеры.** Мышь — наведение с задержкой ≈ 150 мс; клавиатура — фокус на постере (Tab) с задержкой ≈ 300 мс; touch — **постер ведёт на страницу**, а на touch-устройствах (`hover: none`) в углу постера кнопка «ⓘ» (цель 44 px) открывает карточку как нижнюю панель с кнопкой «Открыть».
3. **Содержимое.** Название, год, страна, **все жанры**, возраст (H-25), рейтинги (IMDb, TMDB, сайт), описание (до 4 строк + «Подробнее»), режиссёр или создатель, первые 5 актёров, состояние выхода (одна строка).
4. **Правила.** Один открытый слой за раз; позиционирование: справа от постера, при нехватке места — слева или над; ширина ≤ 360 px; Esc закрывает; курсор можно перевести на слой, он не исчезает (`R-A11Y-05`); данные подгружаются по намерению и кэшируются ≈ 5 минут (`R-PERF-11`), размер ответа ≤ 3 КБ; при `prefers-reduced-motion` — без анимации.
5. **Состояния.** Загрузка — каркас слоя с размерами; ошибка — слой не показывается (информация остаётся на странице).
6. **Стекло.** Допустимо (`R-DES-21`: «карточка постера при наведении»); текст на подложке с контрастом ≥ 4,5:1 (`R-DES-23`).
7. **Приёмка.** *Дано* мышь над постером 200 мс; *тогда* слой с данными появляется, запрос один и кэшируется. *Дано* Tab на постер; *тогда* слой появляется, Esc закрывает. *Дано* `hover: none`; *тогда* виден «ⓘ», нажатие открывает панель.
8. **Edge cases.** EC-K11.
9. **UI.**

```
┌ постер ┐ ┌ слой (стекло, ≤ 360) ───────────────┐
│  2:3   │ │ Название · 2019 · США · 16+           │
│        │ │ Драма · Криминал · Триллер            │
│ ⓘ(touch)│ │ IMDb 8,7   TMDB 8,2   Сайт —          │
└────────┘ │ Описание до 4 строк … Подробнее       │
           │ Режиссёр · в ролях: …                  │
           │ Выходит · следующая серия 12 окт       │
           └───────────────────────────────────────┘
```
   **Фокус:** название и рейтинги (верх слоя).
10. **КП.** Диаграмма компонентов UI.

**Остальные измерения шаблона.**
- **Роли.** Все.
- **Сценарий.** Пользователь наводит курсор, фокусирует постер или нажимает «ⓘ» → слой появляется → читает → закрывает или переходит на страницу сериала.
- **Альтернативы и ошибки.** Сбой запроса — слой не показывается, информация остаётся на странице; нет описания — строка скрыта.
- **Данные.** Один сериал: название, год, страна, жанры, возраст, рейтинги, описание, режиссёр или создатель, пять актёров, состояние выхода (≤ 3 КБ).
- **Валидация и лимиты.** Идентификатор сериала проверяется; кэш ответа ≈ 5 минут; задержка намерения ≈ 150 мс.
- **Побочные эффекты.** EV-04 `poster_card_open` (способ открытия).

## F-02-08 «Похожие» (базовые) · P0

1. **Назначение.** Продолжение просмотра; слот, который позже займёт алгоритм M11.
2. **Правила.** Сходство — по общим признакам с весом **редкости признака** (IDF): жанры, ключевые слова, страна, десятилетие, общие люди (режиссёр/создатель); из выдачи исключаются сам сериал, архивные и непубликуемые; берём 6 лучших, равенство — по голосам IMDb; значения рассчитываются после каждого импорта и кэшируются (H-44).
3. **Состояния.** Меньше 6 кандидатов — показываем сколько есть; нет признаков — блок скрыт.
4. **Приёмка.** *Дано* сериал с жанрами «Криминал, Драма»; *тогда* в «Похожих» нет самого сериала, нет архивных, не более 6, порядок по убыванию сходства.
5. **UI.** 6 постер-карточек с UI-10. **Edge cases.** EC-K12. **КП.** Операция «расчёт сходства» (в ПЗ — описание алгоритма).
6. **Примечание.** M11 заменит алгоритм в этом же слоте (метка «Похожие по вкусу» для вошедших).

**Остальные измерения шаблона.**
- **Роли.** Все.
- **Триггер.** Загрузка страницы сериала.
- **Сценарий.** После импорта система считает сходство и сохраняет шесть лучших; страница показывает готовый список.
- **Альтернативы и ошибки.** Расчёт не удался — показывается прежний список; списка нет — блок скрыт.
- **Данные.** Пары «сериал → похожий → вес», обновляются после импорта; признаки — жанры, ключевые слова, страна, десятилетие, люди.
- **Валидация и лимиты.** Не более 6; исключаются сам сериал, архивные, неопубликованные.
- **Побочные эффекты.** Клик пишет `reco_click` с алгоритмом «content» (EV-14, M11).

## F-02-09 Персона (S-15) · P1

1. **Назначение.** Видеть, где ещё снимался человек из каталога.
2. **Сценарий.** Имя, роль(и) в каталоге (актёр / режиссёр / создатель), сетка сериалов каталога с участием, по популярности. Без фото (инициалы на плашке). Источник — IMDb `name.basics`.
3. **Правила.** Человек публикуется, если связан хотя бы с одним видимым сериалом; `slug` — латиницей из имени (H-32); индексация — да, при ≥ 2 сериалах, иначе `noindex`.
4. **Приёмка.** *Дано* человек связан с 3 видимыми сериалами; *тогда* страница показывает 3 постера. Один сериал ушёл в архив → показываются 2.
5. **UI.** Заголовок и сетка; фокус — имя. **Edge cases.** EC-K13.

**Остальные измерения шаблона.**
- **Роли.** Все.
- **Триггер.** Нажатие на имя в «В ролях» или в карточке; адрес персоны.
- **Альтернативы и ошибки.** Нет видимых сериалов — 404.
- **Состояния.** Загрузка (скелет заголовка и сетки) · ошибка · персоны нет — 404.
- **Данные.** E-Person (имя, `nconst`, `slug`), E-SeriesPerson (роль, персонаж, порядок).
- **Валидация и лимиты.** `slug` — латиница, цифры, дефис; в сетке до 60 сериалов, дальше постранично.
- **Побочные эффекты.** `page_view` (EV-01).
- **КП.** Диаграмма классов (человек–сериал).

## F-02-10 Рейтинги: показ и нормализация · P0

1. **Назначение.** Единообразно показывать рейтинги разных платформ рядом с рейтингом сайта.
2. **Правила.** Компонент «Рейтинг»: платформа, значение в оригинальной шкале, голоса (сокращённо), подсказка «по данным на {дата}», текст `aria-label` («IMDb: 8,7 из 10»). Для правил (сортировка, «Классика» ≥ 8,5) значение приводится к 10-балльной шкале: 0–10 как есть, проценты и 0–100 делятся на 10. Порядок: IMDb, TMDB, сайт, остальные по порядку справочника. Нет значения — «Нет оценок». Цветом не кодируем; ключевое число — моноширинный ярус (`R-DES-04`).
3. **Приёмка.** *Дано* значение 92% у платформы с шкалой «%»; *тогда* на экране «92%», в сортировке участвует как 9,2. *Дано* нет рейтинга IMDb; *тогда* «Нет оценок», сериал не участвует в «Классике».
4. **Edge cases.** EC-C9, EC-K14.

**Остальные измерения шаблона.**
- **Роли.** Все (показ); ручные платформы вводит админ (F-10-03).
- **Триггер.** Показ любой страницы или карточки с рейтингом.
- **Сценарий.** Компонент получает рейтинги сериала, показывает оригинал, голоса, дату и приводит значение к 10-балльной шкале для правил.
- **Альтернативы и ошибки.** Нет значения — «Нет оценок»; значение вне шкалы не показывается и попадает в предупреждение админу (EC-C9).
- **Состояния.** Есть · нет оценок · мало оценок (TMDB < 10 голосов) · устарело (> 12 месяцев — подсветка у админа).
- **Данные.** E-RatingPlatform (шкала, порядок, основная), E-ExternalRating (платформа, значение, шкала, голоса, ссылка, дата снятия).
- **Валидация и лимиты.** Значение в границах шкалы; голоса ≥ 0.
- **Побочные эффекты.** Нормализованное значение участвует в «Классике» и сортировке каталога.
- **UI.** Строка «платформа + число крупно», подсказка по наведению и фокусу (`R-A11Y-05`); цветом не кодируется.
- **КП.** Алгоритм нормализации — в ПЗ 4.2.4.

## F-02-11 Карта сайта, robots, адреса · P0

1. **Назначение.** Индексируемость и корректные адреса (`R-SEO-01…06`, `R-SEO-15`).
2. **Правила.**
   - **`slug`:** латиницей из оригинального или английского названия; при совпадении — `-{год}`, затем `tt…` (H-32); создаётся один раз, меняет только админ; прежние адреса хранятся для 301.
   - **Карта:** индекс карт и файлы по ≤ 50 000 адресов: сериалы, сезоны, серии (только индексируемые), жанры (≥ 6 сериалов), подборки, люди (≥ 2 сериала), статические; `lastmod` меняется только при реальном изменении; в записях — альтернативные языки только у индексируемых EN-страниц; обновляется после импорта и ежедневно.
   - **`robots.txt`:** закрыть `/admin`, `/mod`, `/analytics`, `/api`; ссылка на карту.
   - Статусы: неизвестное — 404, архив — 410, смена адреса — 301.
3. **Приёмка.** *Дано* серия без описания; *тогда* её нет в карте сайта. *Дано* EN-страница без перевода; *тогда* её нет в карте и нет `hreflang` на неё. *Дано* два сериала с одинаковым названием; *тогда* у второго `slug` с годом.
4. **Edge cases.** EC-I9, EC-K15.
5. **КП.** Раздел «SEO» пояснительной записки.

**Остальные измерения шаблона.**
- **Роли.** Роботы и все (публичные файлы).
- **Триггер.** Запрос `/sitemap.xml` и `/robots.txt`; пересчёт после импорта и ежедневно.
- **Сценарий.** Система собирает индексируемые адреса, разбивает на файлы, отдаёт индекс; `robots.txt` статичен и содержит адрес карты.
- **Альтернативы и ошибки.** Ошибка генерации — отдаётся последняя удачная карта; нет страниц какого-то типа — файл не создаётся.
- **Состояния.** Не применимо: у файлов нет интерфейса.
- **Данные.** Сериалы, сезоны, серии, жанры, подборки, люди (только индексируемые); `lastmod` — время реального изменения.
- **Валидация и лимиты.** ≤ 50 000 адресов и ≤ 50 МБ на файл; адреса абсолютные, с языковым префиксом.
- **Побочные эффекты.** Запрос карты ничего не пишет; ответ кэшируется.
- **UI.** Не применимо.

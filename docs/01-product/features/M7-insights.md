# M7 — Персональные итоги (Wrapped): глубокая спека

> v0.1 · Фаза 4, партия 8 · **P1** · экран S-33 · операция OP-12. Опирается на `M3-tracking` (точные отметки `exact`), `M1-identity` (настройки приватности), `ANALYTICS` EV-15, `A11Y`, `I18N`. Не содержит собственных сущностей: итоги — **представление существующих отметок**, ничего не копируется и не дублируется.
> Метки: **[ГИПОТЕЗА]**, **[проверить]**. Номера измерений — по `PLAN` §5.

## 0. Сквозное для модуля

**Что считается итогом.** Только **точные** отметки (`precision = exact`). Ретро-отметки исключены полностью: человек отметил 20 серий одним нажатием «отметить всё до этой», и включение их в «любимое время суток» дало бы правдоподобный, но бессмысленный результат. Это единственное правило, которое делает итоги честными, и оно записано в M3 при определении сущности.

**Минимум данных.** Ниже порога экран не показывается — вместо него объяснение, что делать. Порог: **[ГИПОТЕЗА] 50 точных отметок**, или 10 сериалов с отметками — что наступило раньше.

**Периоды.** Год (2026), месяц (текущий), всё время. Период по умолчанию — год. Период задаётся адресом, а не состоянием вкладки: итоги — ссылка, которой можно поделиться, кроме персональных.

**Приватность.** Итоги публичны только по явному включению (настройка `profile_public`). По умолчанию выключено (`M1` F-01-06, H-73). **Шеринг-картинка всегда без ника**, независимо от настройки: это то, что человек отправляет вовне.

**Сущности:** собственных нет. Читаются `e_watch_mark` (точные), `e_series`, `e_episode`, `e_season`, `e_external_rating`. Кэш итога — производный, не хранится: считать дешевле, чем хранить инвалидируемый кэш.

## F-07-01 Формирование итогов (OP-12) · P1

1. **Назначение.** Показать человеку, что он реально посмотрел, без приукрашивания.
2. **Роли.** Зритель и выше.
3. **Триггер.** Переход по адресу итогов; либо автоматическое приглашение раз в год.
4. **Сценарий.** Считаются слайды по точным отметкам за выбранный период: (1) сколько серий и часов; (2) любимый сериал по числу отмеченных серий; (3) любимое время суток отметок; (4) самый длинный марафон подряд; (5) любимый жанр по средней оценке при минимуме двух сериалов; (6) сериал, который бросили чаще всего; (7) сколько сериалов в планах осталось. Каждый слайд — одно утверждение, одно число.
5. **Альтернативы и ошибки.** Данных меньше порога — экран «пока мало данных» со списком того, что можно отметить, и прямой ссылкой на S-01. Период без данных — «за этот период ничего не отмечено», без пустых слайдов. Сериал удалён — слайд про него пропускается, а не показывает название без ссылки.
6. **Состояния.** Нет доступа · мало данных · загрузка · слайды · финальный слайд с шерингом.
7. **Данные.** `e_watch_mark` (только `exact`), `e_series`, `e_external_rating`.
8. **Правила.**
   - (а) **Только точные отметки.** Ретро-отметки не участвуют ни в одном слайде.
   - (б) «Часы» считаются как сумма длительностей серий с отметкой, а не как время в приложении: у нас нет и не будет данных о времени просмотра, и выдумывать их нельзя.
   - (в) Любимое время суток — по локальной зоне пользователя на момент отметки; хранится UTC, приводится при чтении.
   - (г) Любимый жанр — по средней оценке при ≥ 2 сериалах, иначе слайд пропускается: «любимый жанр» по одной оценке — это шум.
   - (д) Каждый слайд содержит ссылку на сериал, о котором говорит, — итоги должны вести в каталог, а не быть витриной.
   - (е) Ни одно число не округляется в свою пользу: «≈ 47 серий» не пишется, если их 47.
9. **Валидация и лимиты.** Период — от 1 дня до 5 лет; максимум 8 слайдов.
10. **Edge cases.** EC-W1, EC-W2, EC-W3.
17. **Побочные эффекты.** EV-15; вычисление занимает до 300 мс.
18. **Приёмка.** *Дано* 300 отметок, из них 40 ретро; *тогда* в итогах участвуют 260. *Дано* сериал отмечен в 04:00 по UTC, но в 07:00 по Europe/Minsk; *тогда* в «любимом времени суток» он попадает в утро. *Дано* в жанре один оценённый сериал; *тогда* слайд «любимый жанр» не показывается.
19. **UI.** Один факт на слайд, число крупно:

```
┌ Итоги за 2026 ──────────────────────────────┐
│                                            │
│              47                             │  ← одно крупное число
│         сериалов отмечено                  │     и одно утверждение
│                                            │
│   ● ● ● ● ● ● ○ ○ ○ ○   ← прогресс 6 из 8 │
│                                            │
│   ‹                            далее ›    │
└────────────────────────────────────────────┘
```
   **Фокальная точка:** крупное число — оно и есть слайд. **Телефон:** то же, автопереход отключён, листается вручную. **Планшет и десктоп:** то же. **Скелето��:** прямоугольник под число, подпись в одну строку.
20. **КП.** Скриншот на плакат «скриншоты окон» — один из самых узнаваемых экранов проекта.

## F-07-02 Просмотр, листание, автопереход (S-33) · P1

1. **Назначение.** Дать пройти итоги и уйти в любой момент.
2. **Роли.** Зритель и выше.
3. **Триггер.** Открытие S-33.
4. **Сценарий.** Слайды идут по порядку, переключение вручную кнопками, стрелками и свайпом. Автопереход через `wrapped.slide_advance_ms`, если пользователь не взаимодействовал. На последнем слайде — предложение поделиться.
5. **Альтернативы и ошибки.** Пользователь ушёл со слайда и вернулся — возврат на первый слайд, а не на тот, где остановился: с возвратом сложнее, чем без него. `prefers-reduced-motion` — автопереход отключается, остаётся ручное переключение.
6. **Состояния.** Слайд · последний слайд · автопереход · пауза при фокусе.
7. **Данные.** Слайды приходят одним ответом; каждый слайд — это заголовок, число и текст. Данные слайдов не хранятся, считаются на запрос.
8. **Правила.**
   - (а) Каждый слайд читается вслух целиком: заголовок, число, пояснение. Слайд, состоящий только из числа, — это изображение, а не доступный текст (`R-A11Y-19`).
   - (б) Автопереход останавливается при фокусе на любом элементе слайда.
   - (в) `Esc` завершает просмотр и возвращает на страницу, откуда пришли.
9. **Валидация и лимиты.** Не более 8 слайдов; автопереход не более одного за 8 секунд.
10. **Edge cases.** EC-W4.
17. **Побочные эффекты.** EV-15 `recap_slide_view` — по факту показа, не по намерению.
18. **Приёмка.** *Дано* пользователь на слайде 3; *когда* проходит 8 секунд без действий; *тогда* переход на слайд 4. *Дано* фокус на кнопке «далее»; *тогда* автопереход не происходит, пока фокус там.
19. **UI.** То же, что F-07-01, с индикатором паузы при фокусе.
20. **КП.** Не выносится на чертежи.

## F-07-03 Шеринг-картинка · P1

1. **Назначение.** Дать поделиться итогами так, чтобы это не было персональными данными.
2. **Роли.** Зритель и выше.
3. **Триггер.** Кнопка «Поделиться» на последнем слайде.
4. **Сценарий.** На сервере собирается картинка 1080×1350 из фактов: период, четыре самых показательных числа, любимый сериал (название и постер). **Без ника, без email, без аватара.** Ссылка ведёт на публичные итоги, если человек их открыл, иначе — на страницу входа.
5. **Альтернативы и ошибки.** Ник скрыт настройкой приватности — на картинке его нет в любом случае. Постер не загрузился — заглушка с названием. Ссылка приватная — предлагается открыть профиль публично явно, а не молча.
6. **Состояния.** Не готово · готово · ошибка сборки.
7. **Данные.** Только факты для картинки: период, числа, любимый сериал, постер. Ник, email и аватар в набор не входят ни при каких настройках.
8. **Правила.**
   - (а) **Ника, email и идентификатора на картинке нет ни при каких настройках.** Это не настройка, а свойство формата.
   - (б) Картинка — это PNG, а не HTML-страница со скриншотом: она не тянет куки и не отслеживает открытие.
   - (в) Ссылка открывает итоги только при `profile_public`; иначе — страница входа с объяснением.
   - (г) Сборка — на сервере, чтобы в браузере не тянуть шрифты и не собирать вёрстку.
9. **Валидация и лимиты.** Картинка до 2 МБ; ссылка живёт, пока итоги публичны.
10. **Edge cases.** EC-W5.
17. **Побочные эффекты.** EV-15 `recap_share`.
18. **Приёмка.** *Дано* профиль публичный; *когда* пользователь делится; *тогда* на картинке нет ника и email, есть период и числа, а ссылка открывает итоги. *Дано* профиль приватный; *тогда* ссылка ведёт на страницу входа с объяснением, а не на пустоту.
19. **UI.** Предпросмотр перед отправкой:

```
┌ Поделиться ──────────────────┐
│  ┌───────────────┐          │
│  │  Итоги 2026   │          │  ← предпросмотр картинки
│  │  47 сериалов  │          │
│  │  [постер]     │          │
│  └───────────────┘          │
│                              │
│  ☐ Публичные итоги           │  ← иначе ссылка не откроется
│                              │
│  [ Скачать ]   [ Копировать ссылку ] │
└──────────────────────────────┘
```
   **Фокальная точка:** флажок публичности — без него ссылка бессмысленна, и это надо показать до нажатия. **Телефон:** предпросмотр во всю ширину. **Скелтон:** прямоугольник 3:4.
20. **КП.** Скриншот на плакат.

| ID | Ситуация | Поведение | Где |
|---|---|---|---|
| EC-W1 | Отметок 40, из них 30 ретро | Порог не пройден: показывается «пока мало данных» и подсказка, что стоит отметить ещё серии вручную | F-07-01 |
| EC-W2 | Все сериалы периода удалены из каталога | Слайды пропускаются, остаётся то, что считается по отметкам без сериалов; пустых слайдов нет | F-07-01 |
| EC-W3 | Один жанр с двумя сериалами и одним с тремя, средние оценки равны | Жанр выбирается по числу сериалов, при полном равенстве слайд пропускается | F-07-01 |

| EC-W5 | Итоги публичны, но автор сменил ник | Картинка шеринга не содержит ника и не меняется; ссылка показывает актуальный ник | F-07-03 |

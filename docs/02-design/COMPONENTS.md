# COMPONENTS — библиотека компонентов

> v0.1 · Фаза 4 · закрывает `PLAN` §7. Каталог компонентов: 13 оболочечных (`UI-01…UI-13`, владелец — M0) плюс прикладные. Спецификации поведения — в модулях, здесь — **внешний вид и общие требования**.

## 1. Правила для всех компонентов

1. **Только токены** из `TOKENS.md`. Hex в компоненте — ошибка.
2. **Фокус виден всегда** и не обрезается родителем.
3. **Состояние дублируется не цветом**: значком или текстом (R-DES-09).
4. **Цель касания ≥ 44 px**, расстояние между соседними ≥ 8 px.
5. **Компонент не содержит бизнес-логики** — получает данные, зовёт колбэк.
6. **Скелетон повторяет форму**: тот же блок, что и содержимое (M0 F-00-04).
7. **Компонент без состояний не готов.** Минимум: обычный · наведение · фокус · нажатие · отключённый · загрузка.

## 3. Прикладные компоненты

| Компонент | Где описан | Ключевое требование |
|---|---|---|
| Постер | M2 F-02-07 | Пропорция 2:3, одна высота в ряду, `aspect-ratio` |
| Рейтинг-значение | M2 F-02-10 | Три рейтинга в ряд; значение цветом не кодируется |
| Гистограмма оценок | M4 F-04-03 | Распределение и медиана, а не среднее (среднее скрывает полярность) |
| Группа отзывов | M4 F-04-05 | Четыре группы: длина × оценка, средние только в «Все» |
| Кнопка отметки | M3 F-03-02 | «Поставить»/«снять», не «переключить» |
| Ячейка календаря | M3 F-03-05 | До 3 записей и «+N», не сорок |
| Статус материала | M5 F-05-09 | Текстом: «на проверке», «запрещён: спам» |
| Поле со стеклом | M0/M6 | Только над изображением (`MATERIALS-GLASS`) |
| Крупное число | M9/M8 | ≥ 1/3 ширины, отдельный ярус |

## 4. Что ещё обязательно

- **Линтер доступности** в сборке: недостижимый контраст и пустой `aria-label` — ошибка сборки, а не замечание на ревью.
- **Светлая и тёмная темы** у каждого компонента проверяются визуально; вторая тема не «получится сама».
- **Псевдолокаль** (`[Русский]`) проверяется на каждом экране: строка, раздутая на треть, ломает раскладку (M0 F-00-07).
- **Иконки** — одно семейство, один вес линий, только SVG. Эмодзи как иконки запрещены.

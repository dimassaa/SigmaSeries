# LAYOUT-GRID — сетка и раскладка

> v0.1 · Фаза 4 · закрывает `PLAN` §7. Реализует M0 F-00-07. Токены — в `TOKENS.md`.

## 1. Три колонки на десктопе

```
┌──────────┬──────────────────────────────────────┬──────────────┐
│  rail    │            контент                   │  «Предстоящие»│
│  56 px   │            max 1440 px                │   320 px     │
│          │                                      │              │
│  фикс.   │  ширина НЕ меняется при раскрытии     │  ≥ 1280 px  │
│  ширина  │  rail (M0 F-00-01)                    │  иначе скрыта│
└──────────┴──────────────────────────────────────┴──────────────┘
```

Ширина контента **фиксирована** и не зависит от состояния rail. Это и есть причина, по которой rail накладывается, а не сдвигает (M0 F-00-01 правило (а)).

## 2. Границы и колонки

| Ширина | Колонок сетки | Сетка | Правая панель | Rail | Навигация |
|---|---|---|---|---|---|
| < 768 | 4 | 16px, поля 16px | нет | нет | нижняя панель |
| 768–1023 | 8 | 20px, поля 20px | нет | есть | rail |
| 1024–1279 | 12 | 24px, поля 32px | нет | есть | rail |
| ≥ 1280 | 12 | 24px, поля 48px | есть, 320px | есть | rail |

Контент центрируется, максимум 1440 px; дальше — поля, а не растягивание. Блок, ширина которого превышает 6 колонок, центрируется и не растягивается до 12 — иначе строка текста становится нечитаемой.

## 3. Сетка каталога

| Ширина | Постеров в ряду | Ширина постера |
|---|---|---|
| < 768 | 2 | ~calc(50vw − 24px) |
| 768–1023 | 3 | ~200px |
| 1024–1279 | 4 | ~200px |
| ≥ 1280 | 6 | 200px |

Постер 2:3, ширина фиксирована, высота = ширина × 1,5. Все постеры в ряду одной высоты — иначе ряд «зубчит».

## 4. Крупные числа (R-DES-04)

Крупное число занимает **не менее одной трети ширины** контента и стоит на отдельном ярусе без соседей. Пример — `M9` F-09-05: три числа 128 / 94 / 231.

Крупных чисел на экране — **не больше трёх** (M6: по одному на баннер; M8: пять, но это дашборд, где числа и есть содержание). На контентном экране четыре крупных числа — уже не акценты, а шум.

## 5. Фокальная точка и трети

Каждый экран имеет **одну** доминанту (R-DES-01). Правило третей (`R-DES-02`):

- **Левый верхний угол** — текстовые блоки: заголовок, описание, фильтры.
- **Правый верхний угол** — объект: кадр, аватар, изображение.
- **Центр** — только для намеренно фокусного экрана (заставка, пустое состояние, слайд итогов).

Пример из M2 F-02-01: плашка с названием и тремя рейтингами в левой трети шапки, объект кадра — в правой за плашкой.

## 6. Контрольные ширины

Проверяются **всегда**, на каждом экране (M0 F-00-07): **360, 768, 1440**. Промежуточные 1024, 1280 — границы перестроения, между ними раскладка тянется, но не перестраивается.

Контрольный список: (1) число колонок 6 → 3 → 1; (2) CLS = 0 при переходах; (3) фокус ровно один; (4) псевдолокаль не ломает ни одну строку; (5) системный шрифт 200% ничего не обрезает.

# MOTION — движение и его границы

> v0.1 · Фаза 4 · закрывает `PLAN` §7. Правила `R-DES-25…28`.

## 1. Единственное жёсткое правило

**Анимируются только `transform` и `opacity`** (R-DES-25). Всё остальное — `width`, `height`, `top`, `left`, `box-shadow` — браузер пересчитывает на каждом кадре и вызывает перерасчёт раскладки. Именно это и вызывает то подёргивание панели, которое `input/spec.md` называет первым дефектом.

Проверка: если после правки `Performance` показывает «Layout» или «Paint» вместо «Composite» — анимация сделана неправильно.

## 2. Длительности

| Токен | Значение | Где |
|---|---|---|
| `--dur-fast` | 120 мс | наведение, нажатие, смена состояния |
| `--dur-base` | 200 мс | появление, раскрытие |
| `--dur-slow` | 320 мс | переход между страницами, раскрытие rail |
| `--dur-splash` | 1200 мс | затухание кадра заставки (M0 F-00-06) |

Длительность привязана к **расстоянию**: чем больше перемещение, тем дольше. Появление элемента рядом — быстро, переход между страницами — медленно.

## 3. Кривые

| Кривая | Где |
|---|---|
| `cubic-bezier(0.2, 0, 0, 1)` | появление, раскрытие |
| `cubic-bezier(0.4, 0, 0.2, 1)` | уход, смена состояния |
| `linear` | бегущая строка, счётчик заставки, карусель |

Кривая без ускорения — признак лени, а не точности.

## 4. Что двигается, а что нет

| Элемент | Движение |
|---|---|
| Rail (M0 F-00-01) | `translateX` подписей, **ширина не меняется** |
| Появление попапа | `opacity` + `translateY` 4px |
| Переключение слайда карусели | `translateX` ряда |
| Бегущая строка подборок (M6 F-06-04) | `translateX` бесконечно; **пауза при наведении и фокусе** |
| Заставка (M0 F-00-06) | смена кадра; **счётчик линейно** |
| Карточка постера при наведении | **без движения**: меняется только тень и толщина границы |
| Скелетон | статичный или очень медленная волна |

Последние две строки важны: карточка, которая «подпрыгивает» при наведении, раздражает сильнее, чем отсутствие реакции.

## 5. `prefers-reduced-motion`

Пользователь попросил — движение выключается **полностью**, а не ослабляется (R-DES-27):

- бегущая строка стоит, доступна прокруткой и кнопками;
- счётчик заставки не тикает;
- смена кадров заставки отключается;
- раскрытие rail мгновенное;
- скелетон статичный;
- остаются `opacity`-переходы ≤ 100 мс — они не вызывают укачивания.

## 6. Запрещено

Автопрокрутка карусели; параллакс; «отскок» (bounce) на кнопках; пульсация; анимация числа, которое пересчитывается; параллельные анимации дольше 500 мс.

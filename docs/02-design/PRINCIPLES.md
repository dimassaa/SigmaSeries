# PRINCIPLES — дизайн-принципы (проверяемые правила)

> v0.1 · Фаза 3. Закрывает D-02…D-15 из `PLAN` §2.3. Правила пронумерованы `R-DES-NN`: на них ссылаются макеты, тесты и AGENTS. Токены (конкретные значения цветов, размеров) — позже, после макетов экранов. Метки: **[ГИПОТЕЗА]** — стартовое значение, проверяем на прототипе.

## 1. Иерархия источников

1. Требования автора: функция определяет форму, правило третей, фокальная точка, 60-30-10, крупные ключевые цифры, меньше скруглений и «ИИ-атрибутов».
2. `Design.md` — нормы интерфейса (кроме конфликтов D-11…D-15, решённых ниже).
3. OpenSea — структура и плотность оболочки (rail, панели, кольца вместо теней).
4. 21 TSI — только сцена заставки.

## 2. Сцены

| Сцена | Где | Эталон | Допускается | Нельзя |
|---|---|---|---|---|
| Оболочка | Все обычные страницы | OpenSea + стекло по §7 | Плотная сетка, кольца-границы, стекло над изображениями | Стекло на плоском фоне, декор |
| Заставка | Первый визит | 21 TSI | Чёрный и белый, огромные цифры, чистая типографика | Стекло, акцентный цвет, текст поверх кадра |
| Итоги | `/recap` | Токены оболочки, плакатная типографика | Крупные числа, один акцент, формат 9:16 для шеринга | Новая палитра, чужие референсы |
| Рабочие панели | Редактор, аналитик, админ | Плотные таблицы | Палитра данных, горячие клавиши | Стекло в рабочих областях, анимации ради анимаций |

## 3. Композиция и иерархия

| ID | Правило |
|---|---|
| R-DES-01 | **Одна доминанта.** У каждого экрана и блока один фокальный элемент; в макете экрана он назван. |
| R-DES-02 | **Сетка третей.** Главный объект и текст стоят на линиях и пересечениях третей. Текст баннера — в левой трети; лица и объекты кадра — вне зоны текста. Автофокус изображений следует правилу третей, админ может поправить. |
| R-DES-03 | **Не более 3 уровней в карточке:** название, ключевой атрибут, остальное. |
| R-DES-04 | **Ключевые цифры — отдельный ярус:** крупнее текста, моноширинные цифры (`tabular-nums`). К ним относятся рейтинг на баннере, «через N дней», KPI, прогресс просмотра. Не более 3 крупных чисел на экран. |
| R-DES-05 | **Отступы по близости:** связанное ближе, группы дальше; значения только из шкалы (4, 8, 12, 16, 24, 32, 48, 64). |
| R-DES-06 | **Один основной (primary) на действие**, остальные — вторичные и третичные. |

## 4. Цвет

| ID | Правило |
|---|---|
| R-DES-07 | **60-30-10:** 60% — базовые поверхности, 30% — вторичные поверхности и текст, 10% — акцент. Один акцентный оттенок. Проверка — по скриншоту экрана. |
| R-DES-08 | Акцент — только для главного действия, активной навигации, фокуса, ключевых чисел и ссылок. Не декор. |
| R-DES-09 | Состояния (успех, ошибка, предупреждение) — отдельные токены; цвет всегда дублируется текстом или иконкой. |
| R-DES-10 | Палитра данных — отдельная: ≥ 6 различимых цветов, безопасная для дальтоников; проверка симулятором. |
| R-DES-11 | Нет чистых `#000` и `#FFF` в оболочке; тёмная тема — не инверсия, светлая — отдельный набор поверхностей. Исключение: сцена заставки (D-14). |
| R-DES-12 | Насыщенность акцента подбирается для каждой темы по контрасту и «вибрации» (D-13): ни «насыщеннее», ни «приглушить» вслепую. |
| R-DES-13 | Градиенты — только функциональные: затемнение под текстом, фон стекла (D-11). |

## 5. Типографика

| ID | Правило |
|---|---|
| R-DES-14 | Одно семейство для интерфейса (кириллица + латиница) и моноширинное для чисел и данных. Лицензия должна допускать самостоятельный хостинг. |
| R-DES-15 | Основной текст ≥ 16 px, строка 45–75 знаков, абзац от 4 строк — по левому краю, интерлиньяж 1,4–1,6. |
| R-DES-16 | Размеры по модульной шкале; один `h1` на страницу; заголовки семантические, а не стилевые. |
| R-DES-17 | Шрифты: самостоятельный хостинг, подмножество, `font-display: swap`, предзагрузка ≤ 2 файлов, запасной шрифт с `size-adjust` (CLS = 0). Подробности — `PERFORMANCE`. |

## 6. Форма

| ID | Правило |
|---|---|
| R-DES-18 | Радиусы 0 / 2 / 4 / 8; радиус вложенного = внешний − отступ; круг — только аватар; «пилюль» нет (теги — 4). |
| R-DES-19 | Границы — тонкое кольцо (hairline) вместо теней; минимальная тень — только у плавающих слоёв (карточка, меню, модальное окно). |

## 7. Материалы: стекло

Принцип: **стекло означает «слой над содержимым или изображением».** Над плоским фоном — обычная поверхность.

| ID | Правило |
|---|---|
| R-DES-20 | Стекло только поверх изображения или другого содержимого. |
| R-DES-21 | **Разрешено:** развёрнутый rail, карточка постера при наведении, плашка текста на баннере и странице сериала, модальные и выдвижные панели, выпадающие меню, мобильная нижняя панель. **Запрещено:** сетки карточек, таблицы, графики, тексты для чтения (отзывы, руководства), поля форм. |
| R-DES-22 | **Бюджет:** не более 2 одновременных размытых слоёв в окне на мобильном и 3 на десктопе; радиус размытия 12–24 px **[ГИПОТЕЗА, замер в Фазе 7]**. |
| R-DES-23 | Текст на стекле: контраст ≥ 4,5:1 на худшем фоне (самом светлом и самом тёмном кадре) ⇒ минимальная непрозрачность подложки задаётся токеном. |
| R-DES-24 | Запасные варианты: нет `backdrop-filter`, режим уменьшенной прозрачности, режим повышенного контраста — сплошная поверхность из тех же токенов. |

## 8. Движение

| ID | Правило |
|---|---|
| R-DES-25 | Анимируем только `transform` и `opacity`; не ширину, высоту и позицию, вызывающие перераскладку. Rail: ширина колонки не меняется, развёрнутая панель — наложение. |
| R-DES-26 | Микро 120–200 мс, панели 250–350 мс, без «пружин». `prefers-reduced-motion` — мгновенно или короткое появление. |
| R-DES-27 | Автодвижение (бегущая строка, смена баннеров, заставка) — только с паузой, остановкой при наведении и фокусе, не более трёх одновременно. |
| R-DES-28 | Скелетон имеет размеры контента; показывается, если данные не пришли за ≈ 150 мс (иначе без мигания); блик без анимации по всей ширине. |

## 9. Раскладка и адаптив

| ID | Правило |
|---|---|
| R-DES-29 | Брейкпоинты 640 / 1024 / 1280, мобильный первым. Rail 56 px; правая панель 320 px от 1280. |
| R-DES-30 | Цели касания ≥ 44 px на touch (минимум по WCAG 2.2 — 24 px). |
| R-DES-31 | У каждой hover-механики есть аналог для клавиатуры и touch (rail, меню жанров, карточка постера, бегущая строка). |
| R-DES-32 | Запас под русский текст: нет фиксированной ширины у подписей; проверка псевдолокалью (+30%). |

## 11. Данные, итоги, рабочие инструменты

| ID | Правило |
|---|---|
| R-DES-40 | **Дашборды:** число крупно + изменение (стрелка, знак, текст); прямые подписи вместо легенд, где возможно; единые периоды; пустое состояние с причиной; бейдж «демо-данные» для синтетики. |

| R-DES-42 | **Рабочие инструменты:** плотность и скорость важнее украшений; горячие клавиши; необратимые действия — подтверждение с перечнем последствий и повторным паролем. |

## 12. Запрещённые «ИИ-признаки»

| ID | Правило |
|---|---|
| R-DES-43 | Не используем: свечение и неоновые тени; сине-фиолетовые градиенты и градиентный текст; декоративные эмодзи; иконки в кружках как украшение карточек; три одинаковые карточки «преимуществ»; «искры» для AI-функций; плавающие размытые пятна; большие радиусы; стекло везде; выдуманные цифры и отзывы; центрованные полотна текста; текст-заглушки. |

## 13. Чек-лист применения к экрану (проходим при каждом макете)

1. Назван фокальный элемент? (R-01) · Что на линиях третей? (R-02)
2. Не более 3 уровней в карточках, ≤ 3 крупных чисел? (R-03, R-04)
3. Один primary на действие? (R-06) · Отступы из шкалы, по близости? (R-05)
4. Акцент только по назначению, примерно 10% площади? (R-07, R-08)
5. Состояния дублируются не цветом? (R-09)
6. Стекло только над изображением, в рамках бюджета, контраст на худшем фоне? (R-20…R-24)
7. Анимируются только `transform` / `opacity`; есть `reduced-motion`? (R-25, R-26)
8. Скелетон с размерами контента; пустое, ошибочное, офлайн-состояния нарисованы? (R-28)
9. Hover-механики имеют аналог для клавиатуры и touch? (R-31)
10. Проверено на 360 / 390 / 768 / 1280 / 1440 и псевдолокалью? (R-29, R-32)
11. Светлая и тёмная темы — обе проверены? (R-11, R-12)
12. Нет «ИИ-признаков»? (R-43)

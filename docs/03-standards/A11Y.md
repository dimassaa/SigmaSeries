# A11Y — стандарт доступности

> v0.1 · Фаза 3. Цель — **WCAG 2.2 уровня AA**. Правила `R-A11Y-NN` учитывают особенности проекта: стекло, hover-механики, бегущая строка, карусели, заставка, проверки против спама. Номера критериев WCAG даны для сверки. Метки: **[ГИПОТЕЗА]**.

## 2. Проверки

- **Автоматические (CI):** axe на эталонных страницах в обеих темах и обоих языках; проверка контраста на стекле (снимки худших фонов); линтер разметки.
- **Вручную по чек-листу:** клавиатура от начала до конца; масштаб 200% и ширина 320 px; чтение с экрана — NVDA на Windows (по Бланку), VoiceOver на iPhone (аудитория 20–35 сидит с телефонов); `prefers-reduced-motion`; режим повышенного контраста.
- **Критерий приёмки экрана:** 0 серьёзных нарушений axe + пройден ручной чек-лист.

# I18N — стандарт локализации (RU + EN, с запасом под другие языки)

> v0.1 · Фаза 3. Подтверждено автором: **EN как дополнительный язык разрешён**, RU — по умолчанию. Правила `R-I18N-NN`. Данные спайка: описание ru у 95% популярных и у 80% новинок ⇒ резерв при отсутствии перевода обязателен. Метки: **[ГИПОТЕЗА]**.

## 1. Архитектура

- **Языки:** `ru` (по умолчанию), `en`. Добавление нового (например, `be`) не требует изменения кода: каталог сообщений + таблицы переводов + словарь модерации.
- **Три слоя текста:**
  1. *Интерфейс* — каталоги сообщений (формат ICU MessageFormat: множественные числа, выбор).
  2. *Контент каталога* — таблицы переводов (название, описание сериала, серии, жанров, подборок, справочников).
  3. *Материалы пользователей* — не переводятся; хранят метку языка.
- **Определение языка запроса:** адрес `/{locale}/…` → настройка профиля → cookie → `Accept-Language` → по умолчанию `ru`. Автоматических перенаправлений для роботов нет.

## 2. Правила

| ID | Правило |
|---|---|
| R-I18N-01 | Весь текст интерфейса — в каталогах сообщений; в коде и разметке строк нет. Сообщения не склеиваются из кусков. |
| R-I18N-02 | Ключи именуются `экран.компонент.элемент`; для каждого ключа есть `ru` и `en` — **для интерфейса резерва нет, отсутствие ключа ломает сборку (CI)**. |
| R-I18N-03 | Множественные числа и выбор — только через ICU. Русский: формы one / few / many / other («через 1 день / 2 дня / 5 дней»); английский: one / other. Сообщения с числом проверяются на 1, 2, 5, 11, 21. |
| R-I18N-04 | Даты, числа, относительное время — `Intl` с языком пользователя и его часовым поясом. Хранение — UTC. |
| R-I18N-05 | Подписи «сегодня вышло», «завтра», «через N дней» (< 4 дней), иначе дата — единый компонент, одинаковый в панели, календаре и закладках. |
| R-I18N-06 | **Цепочки резерва для контента:** RU: ru → en → оригинал. EN: en → ru (с `lang="ru"` на фрагменте) → оригинал. Название: перевод → оригинальное. |
| R-I18N-07 | Адреса и SEO: отдельные URL по языкам, `hreflang`, `<html lang>`; EN-страница без перевода описания не индексируется (`SEO` R-SEO-04). |
| R-I18N-08 | Материалы пользователей хранят язык (по преобладанию письменности; можно поправить). Фильтр «только мой язык» — по умолчанию выключен. **[ГИПОТЕЗА]** |
| R-I18N-09 | Сортировка и поиск: `Intl.Collator` для языка; поиск нормализует регистр, `ё → е`, исправляет раскладку («ghbdtn» → «привет»), ищет по названиям на ru, en и оригинальному. |
| R-I18N-10 | Тексты в изображениях запрещены (кроме логотипов и постеров из источника); у картинок `alt` локализован. |
| R-I18N-11 | Запас под длину: RU длиннее EN примерно на 20–30%; компоненты без фиксированной ширины подписей; проверка псевдолокалью (+30%, акценты) в CI. |
| R-I18N-12 | CSS с логическими свойствами (`margin-inline`, `padding-inline`) — дёшево оставляет путь к языкам с письмом справа налево. |
| R-I18N-13 | Письма, уведомления, страницы ошибок, юридические страницы и все служебные панели (редактор, аналитик, админ) локализованы так же. |
| R-I18N-14 | Сервер не отдаёт готовых фраз: ошибки — коды, текст по коду подставляется из каталога. |
| R-I18N-15 | Словари модерации ведутся по языкам независимо от языка интерфейса; проверяются оба при любом тексте (`MODERATION`). |
| R-I18N-16 | Термины берутся из `GLOSSARY` (колонка RU и EN) — единый источник; название роли «редактор» в EN — Moderator (H-13). |
| R-I18N-17 | Шрифты содержат кириллицу и латиницу; подмножества для обоих; проверка лицензии для самостоятельного хостинга. |

## 3. Процесс

1. Русский — исходный язык; английский готовим вместе (черновик ИИ + ваша проверка по `GLOSSARY`).
2. Новый ключ = запись `ru` + запись `en` в одном изменении.
3. CI: нет ключа → ошибка; неиспользуемый ключ → предупреждение; псевдолокаль → снимки без переполнений.
4. Контент каталога: русское описание обязательно для «пригодна к показу»; EN — желателен, отсутствие — не ошибка, но снимает индексацию EN-страницы.

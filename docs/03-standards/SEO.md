# SEO — стандарт поисковой оптимизации

> v0.1 · Фаза 3. Правила `R-SEO-NN`. Связано: `I18N` (адреса и hreflang), `PERFORMANCE` (Core Web Vitals), `SCREENS` (какие страницы индексируются). Метки: **[ГИПОТЕЗА]**.

## 1. Правила

| ID | Правило |
|---|---|
| R-SEO-01 | Адреса `/{ru\|en}/…` с понятными slug; при смене slug — 301 со старого. Никаких идентификаторов в адресах индексируемых страниц, кроме запасных для коллизий. |
| R-SEO-02 | У каждой страницы один `canonical`. Фильтры и сортировки каталога канонизируются на базовый адрес (индексируется только «чистый» список и постраничность без фильтров); пустая выдача — `noindex`. |
| R-SEO-03 | Языковые версии связаны взаимными `hreflang` + `x-default`; `<html lang>` всегда задан. |
| R-SEO-04 | EN-страница индексируется только если переведены заголовок и описание; иначе `noindex, follow` и без `hreflang` на неё (иначе дубль русского текста). |
| R-SEO-05 | `sitemap.xml`: индекс с шардированием, `lastmod` только при реальном изменении содержимого, альтернативные языки внутри записей. Только индексируемые страницы. |
| R-SEO-06 | `robots.txt` закрывает служебные разделы (`/admin`, `/mod`, `/analytics`, `/api`). Утилитные страницы (поиск, вход, профиль) отдают `X-Robots-Tag: noindex` и остаются доступными роботу, чтобы он этот запрет увидел. Приватные — за авторизацией. |
| R-SEO-07 | Содержимое индексируемых страниц есть в **начальном HTML** (серверная отрисовка), не только после выполнения скриптов. |
| R-SEO-08 | Заставка и любые оверлеи не скрывают содержимое от роботов; роботов по User-Agent **не определяем** (риск cloaking); заставка — клиентский оверлей поверх готового HTML. |
| R-SEO-09 | Постраничность и «карусели без перезагрузки» имеют настоящие ссылки `<a href>` на страницы (`/series?sort=new&page=2`), скрипты лишь улучшают их. Бесконечной прокрутки без ссылок нет. |
| R-SEO-10 | Заголовок и описание по шаблонам (таблица §2); описание ≤ 155 знаков, из описания сериала; без дублей между страницами. |
| R-SEO-11 | Open Graph и Twitter-карточки: изображение 1200×630 из фона сериала (фокальная точка учитывается), заголовок, описание, язык. |
| R-SEO-12 | Разметка JSON-LD по типам страниц (таблица §2) и **только то, что видно на странице**. Для `TVSeries` и `TVEpisode` — как семантика; расширенные сниппеты Google для них не гарантируем **[проверить]**. |
| R-SEO-13 | Ссылки в материалах пользователей запрещены (`SECURITY` R-SEC-14); если появятся — `rel="ugc nofollow"`. |
| R-SEO-14 | **Спойлеры не попадают в сниппеты:** содержимое с пометкой скрыто в разметке и снабжено `data-nosnippet`; описания серий, которые пользователь решил скрыть, не отдаются в HTML вообще. |
| R-SEO-15 | Статусы: неизвестное — 404; снятое с публикации и архив — 410 с полезной страницей («сериал снят, вот похожие»); смена адреса — 301; «мягких 404» (200 с пустой страницей) нет. |
| R-SEO-16 | Core Web Vitals — цели из `PERFORMANCE`; ухудшение ловится в CI и по RUM. |
| R-SEO-17 | «Случайные» блоки (жанры на главной) используют суточное зерно: страница стабильна в течение суток. |
| R-SEO-18 | Структурированные данные и видимый текст не расходятся (рейтинг, число оценок, даты). |
| R-SEO-19 | Изображения: осмысленный `alt` (название сериала и роль картинки), `width` и `height`, современные форматы, ленивая загрузка вне экрана. |
| R-SEO-20 | Внутренняя перелинковка: хлебные крошки, «похожие», жанры, подборки, персоны; у каждой индексируемой страницы ≥ 1 внутренняя ссылка. |

## 2. Шаблоны по типам страниц

| Страница | Индекс | Заголовок (RU) | JSON-LD | Примечание |
|---|---|---|---|---|
| Главная | да | `{Бренд}: календарь выхода серий, рейтинги и отзывы на сериалы` | `WebSite` | Баннер дня — LCP-элемент |
| Каталог `/series` | да (без фильтров) | `Сериалы — каталог, рейтинги, новинки · {Бренд}` | `ItemList` | Страницы `?page=N` с canonical на себя |
| Жанр | да | `{Жанр}: лучшие сериалы · {Бренд}` | `ItemList`, `BreadcrumbList` | При < 6 сериалах — `noindex` |
| Подборка | да | `{Название подборки} — сериалы · {Бренд}` | `ItemList` | |
| Сериал | да | `{Название} ({год}) — рейтинг, даты серий, отзывы · {Бренд}` | `TVSeries`, `BreadcrumbList` | Рейтинг сайта — только при достаточном числе оценок |
| Сезон, серия | да | `{Название}, сезон N, серия M — дата выхода · {Бренд}` | `TVSeason`, `TVEpisode` | |
| Отзывы сериала | да (стр. 1) | `Отзывы на «{Название}» · {Бренд}` | — | Спойлеры — R-SEO-14 |
| Руководство | да | `{Заголовок руководства} — {Название} · {Бренд}` | `Article` | `datePublished`, автор |
| Обсуждение | да | `{Тема} — обсуждение «{Название}» · {Бренд}` | `DiscussionForumPosting` **[проверить]** | |
| Персона | да | `{Имя}: сериалы · {Бренд}` | `Person` | |
| Календарь | да (месяц) | `Календарь выхода серий — {месяц год} · {Бренд}` | — | |
| Остальное (поиск, вход, профиль, настройки, итоги, служебные) | нет | — | — | `noindex` |

# CONTENT-PLAN — что показываем, что делаем при пробелах данных

> v0.2 · закрывает G-24. Принцип автора (DEC-008): данные приходят автоматически из IMDb и TMDB; чего нет — заглушка, карточка всё равно публикуется; админ видит список неполных позиций и дополняет вручную. Откуда что берётся — `DATA-SOURCES.md`. Метки: **[РЕШЕНО]** · **[ГИПОТЕЗА]**.

## 1. Объём

1000 самых популярных сериалов + новинки до декабря ≈ 1000–1250 карточек **[РЕШЕНО]**. При таком объёме правила главной выполняются с запасом; риск не в количестве, а в **полноте**: у части сериалов не будет фона для баннера, дат серий или ru-описания.

## 2. Места показа и требования

| Место показа | Правило (spec + гипотезы) | Заглушка допустима? | Что должно быть |
|---|---|---|---|
| Баннер «Новинка» | Лучший по рейтингу среди сериалов с серией (или целым сезоном), вышедшей сегодня; запасной вариант: серия за 7 дней → ручной выбор | **Нет** | Дата серии, фон 16:9 |
| Баннер «Классика» | Премьера > 10 лет и основной рейтинг ≥ 8,5; без повтора ≥ 14 дней | **Нет** | Фон 16:9, рейтинг IMDb |
| Баннер «Выбор редакции» | Назначает админ на дату; пусто → автовыбор лучшего из не показанных 14 дней | **Нет** | Фон 16:9 |
| Новинки (3 стр. × 6, по кругу) | Премьера ≤ 12 мес; страниц = ⌈n/6⌉, максимум 3 | Да; без постера — ниже в выдаче | Название, год, страна, жанр |
| Подборки (6 в бегущей строке) | 6 самых популярных; видима при ≥ 6 сериалах | Баннер подборки по умолчанию = фон первого сериала; админ может заменить | ≥ 6 сериалов |
| Жанры на главной | 6 сериалов «этого года»; запасное окно: год → 3 года → всё время | Да | ≥ 6 сериалов в жанре |
| Заставка | 12–16 узнаваемых кадров **[ГИПОТЕЗА]**; выбирает админ из изображений TMDB | **Нет** | Кадры 16:9 |
| Правая панель и календарь | Ближайшие выходы; < 4 дней: «сегодня вышло / завтра / через N дней», дальше дата | — (без даты в панель не попадает) | Дата серии |
| Рекомендации | Сходство по жанрам, тегам, людям, подборкам | Да | Жанры, ключевые слова |
| Подробная карточка при наведении | Описание, рейтинги, возраст, жанры, режиссёр, в ролях | Каждое поле — по таблице §4 | — |

## 3. Полнота карточки

| Уровень | Что значит | Что открывает |
|---|---|---|
| Минимум для публикации | Название, год, ≥ 1 жанр, статус | Страница сериала, поиск, жанр, подборки |
| Пригодна к показу | Минимум + постер + описание (ru или en) | Списки, «Новинки», жанры, рекомендации |
| Полная | + фон 16:9 без текста ≥ 1920 px, ru-описание, график серий без пропусков (для «Выходит»), режиссёр или создатель и актёры. Возраст желателен, но не обязателен (EC-D13) | Баннеры, заставка, «Новинка дня» |

**Неполная карточка** — любая, у которой чего-то не хватает до «полной» или есть сомнение в данных. Коды причин и приоритеты — `features/M10-studio` F-10-02: нет в TMDB · сомнительное сопоставление · нет жанра · нет постера · нет фона 16:9 · нет описания · нет описания ru · график с пропусками (только для «Выходит») · нет людей · новый жанр; **информационная** причина «нет возраста для RU/BY» уровень не меняет. «Ждём сезон» — не дефект. Пользователь «неполноту» не видит.

## 4. Что показываем вместо отсутствующего

| Данных нет | Показываем |
|---|---|
| Постер | Нейтральная плашка в стиле интерфейса с названием и годом (без цветового декора) |
| Описание ru | Описание en; если и его нет — «Описание пока не добавлено» |
| Возрастное ограничение для RU/BY | Метка по данным другой страны с пометкой («по данным США») или не показываем (H-25) |
| Режиссёр или актёры | Блок скрывается |
| Рейтинг IMDb / TMDB | «Нет оценок» |
| Даты серий | Сериал не в панели «Предстоящие» и не в «Новинке дня»; в календаре — «график уточняется» |
| Фон 16:9 | Не участвует в баннерах и заставке; на странице сериала — размытая копия постера |

## 5. Изображения

| Роль | Пропорция | Источник | Где | Фокальная точка | Варианты (создаются при загрузке) |
|---|---|---|---|---|---|
| Постер | 2:3 | TMDB | Карточки, списки, поиск | не нужна | 3 ширины |
| Баннер | 16:9 | TMDB, фон без текста | Главная | **автоматически — пересечение третей справа-сверху (2/3, 1/3)**, так как текст баннера стоит в левой трети (`R-DES-02`); админ правит у баннеров и кадров | 3 ширины + мобильная обрезка |
| Фон страницы сериала | 16:9 | TMDB | Страница сериала | автоматически | 3 ширины |
| Кадр заставки | 16:9 | TMDB | Заставка | автоматически / админ | Заранее размытая копия |
| Баннер подборки | 16:9 | фон первого сериала или загрузка админом | Бегущая строка, страница подборки | автоматически | 2–3 ширины |

Правила: изображения хранятся **в БД** (требование Бланка C-04, H-03); отдача — через адрес с долгим кэшированием и версией; современный формат + запасной; для баннеров предпочитаем **фоны без текста** (в TMDB они обычно без языка) **[ГИПОТЕЗА H-22]**, чтобы текст интерфейса не накладывался на чужие надписи; неподходящая пропорция — автообрезка по фокальной точке; загрузка только с разрешённых адресов (защита от SSRF); у изображения есть текстовое описание (название сериала).

## 6. Внешние рейтинги

- **Автоматически:** IMDb (датасет) и TMDB (API).
- **Вручную, необязательно:** Кинопоиск, Rotten Tomatoes (критики и зрители отдельными записями) и любые другие — справочник платформ админ расширяет без кода (DEC-006).
- В подробной карточке по умолчанию: IMDb, TMDB, рейтинг сайта (вместо Кинопоиска — **H-17**).
- **Нормализация:** для правил («Классика» ≥ 8,5, сортировки) значение приводится к 10-балльной шкале; на экране — оригинал (92%, 8,7/10).
- **Свежесть:** по наведению «по данным на {дата}»; значения старше 12 месяцев подсвечиваются у админа.
- Нет основного рейтинга (IMDb) → сериал не участвует в «Классике».
- Названия платформ — текстом, без логотипов **[ГИПОТЕЗА]**.

## 7. Раздел админа (Контент-студия)

**P0**
- **Список неполных карточек:** фильтр по причине, сортировка по приоритету (сначала то, что блокирует баннеры, календарь и главную), счётчик «осталось».
- Правка карточки на месте: поля с происхождением (IMDb / TMDB / вручную); ручное значение **блокируется от перезаписи импортом**.
- Загрузка своего изображения вместо TMDB, выбор фокальной точки, предпросмотр «как на главной / в карточке / на телефоне».
- Массовое задание графика серий («сезон 2: 8 серий, по средам, с 15.10»).
- **Подборки вручную** (создание, порядок, баннер, видимость) — без них бегущая строка на главной пуста; подборки по правилам — P1.
- Запуск импорта, отчёт последнего запуска, индикатор «покрытие расписания до 31.12».
- Архивирование вместо удаления; история изменений; защита от одновременной правки.

**P1**
- Подборки по правилам, «выбор редакции» на календаре, кадры заставки, редактор справочников (начальное наполнение справочников — P0, сид).
- Массовые операции (жанр, статус, публикация).
- Режим «по одному»: карточка за карточкой с кнопками «Сохранить и дальше» / «Пропустить».

Для **редактора** очередь модерации устроена так же: материал за материалом, две кнопки «Одобрить» / «Запретить» (DEC-012); детали — M5.

## 8. Edge cases (старт реестра)

| ID | Ситуация | Поведение |
|---|---|---|
| EC-C1 | Сериал архивируют, а он в баннере, подборке, списках зрителей | Ссылки остаются; с главной скрыт; в списках «снят с публикации» |
| EC-C2 | Меняется адрес (slug) | 301 со старого адреса |
| EC-C3 | Дата серии перенесена | Календарь обновляется, подписчики получают уведомление |
| EC-C4 | Сезон выходит целиком | Одна запись «N серий» на дату; в панели — «все серии» |
| EC-C5 | Загружено изображение не той пропорции или огромное | Автообрезка по фокальной точке + предупреждение; лимит размера |
| EC-C6 | Подборка опустела (< 6 сериалов) | Скрывается с главной, остаётся у админа с пометкой |
| EC-C7 | В жанре «этого года» меньше 6 | Запасное окно (год → 3 года → всё время) |
| EC-C8 | Нет русского описания | Показываем английское; карточка в списке неполных |
| EC-C9 | Рейтинг вне диапазона шкалы | Ошибка валидации при вводе |
| EC-C10 | Сериал в состоянии «Выходит», но у части серий нет даты | Эти серии не попадают в «Новинку дня» и панель; сериал в неполных (причина «график с пропусками»). «Ждём сезон» без дат — не дефект (EC-C14) |
| EC-C11 | Нет ни одного сериала с фоном для баннера «Классика» | Баннер не показывается; админ получает сигнал; главная перестраивается без пустого места |
| EC-C12 | Сегодня не вышло ни одной серии | Запасной вариант: серия за 7 дней → ручной выбор |
| EC-C13 | Сезон вышел целиком (≈ 16% сериалов в спайке) | Один выход «N серий»; «Новинка дня» — премьера сезона; одно уведомление |
| EC-C14 | Сериал «ждёт сезон» (дат нет) | Не в календаре и панели; на странице «Ждём новый сезон»; подписка «сообщить, когда объявят дату» |

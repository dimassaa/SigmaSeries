## 1. Коротко

- **Проект:** сервис оценки и отслеживания сериалов с календарём выхода серий (курсовой, Node.js + Express). До защиты **55–65 дня** (окно 10–20 декабря).
- **Разделение труда:** планирование (спеки, модель данных, архитектура и стек, набор для агента) ведётся здесь; код и документы курсового — автор и агент, старт кода ≈ 2 ноября. Набор для агента — §6.
- **Спеки всех 13 модулей написаны, идёт код P0.** Закрыты M0, M1, M2, M3 (F-03-01…07) и M12; в работе M3 (уведомления). Состояние кода по операциям — `TRACEABILITY` §1.
- **Опережаем график примерно на 1,5 недели** (оценка): этапы 0–3 и четыре модуля этапа 4 закончены раньше плана.
- **Риск №1** — три отступления от задания не согласованы с руководителем: вторая таблица стилей, английский интерфейс, Redis и очереди (`COMPLIANCE-BLANK` §6, DEC-014 подтверждён автором, а не руководителем). Бланк запрещает вольности дословно. **Риск №2** — ревью спек: решения подтверждены, но ни одна из фич не проверена автором.

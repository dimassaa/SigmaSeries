https://component.gallery - базовая галерея самых скучных компонентов

https://www.nbrb.by/coinsbanknotes/byn-ico/nbrb-font - здесь можно взять значек белорусского рубля для отображения на сайте, для тем связанных с финансами будет плюс если вы будете использовать новый дизайн 

https://styles.refero.design - огромная библиотека промптов с дизайнами не просто каких то абстрактных стилей а реальных популярнейших сайтов типа nike и apple, ищешь своих конкурентов и берешь у них самые удачные и проверенные дизайн-решения, будет выглядеть профессиональнее

https://www.untitledui.com/react/components - ещё больше компонентов для реакт

**Use human like language**
Interfaces should speak like a person, not documentation. Clear, human wording builds trust and clarity.

**Spacing shouldn't be equal**
Use spacing to guide the eye and clarify relationships between elements.

**Less is more**
Don't present all the information at once. Break content into scannable sections so users can quickly find what matters to them.

**Use clear CTAs**
Use labels that tell users what will happen next. Outcome driven copy reduces hesitation.

**Instant Errors**
Surface errors instantly so users can fix them in context and keep moving.

**Color for Different UI States**
Colors help users understand what they can interact with. Active states use the brightest color, hover states use a slightly different shade, and disabled elements are grayed out.
See how the button changes color based on its state, and how form fields use red for errors and green for success to clearly communicate status.

**Dark mode considerations**
Dark mode isn't just inverting colors! Reduce contrast slightly, avoid pure white text, and use more saturated accent colors. Compare how this app adjusts its color palette between light and dark modes while maintaining brand identity.

**Color for User Feedback**
Colors tell users what's happening. Green = success, Red = error, Yellow/Orange = warning, See how these notifications use red for errors, green to confirm successful actions, and yellow to draw attention to important decisions.

**Color Hierarchy in UI**
Colors guide users to what's most important. Brightest/boldest colors draw attention first, muted colors recede. Notice how Spotify's vibrant green play button commands your eye while darker elements fade away, and how Netflix uses a bold red "Sign In" button to stand out on its black screen.

**60-30-10 Rule**
The 60–30–10 rule helps create balanced interfaces. Use your neutrals/base color for 60% (backgrounds), primary color for 30% (major elements), and accent color for 10% (buttons, highlights).

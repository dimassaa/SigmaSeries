| `Бланк.md` | Задание курсового проекта от руководителя | руководитель | обязательно, не обсуждается |
| `DESIGN.md` | Style-reference сайта 21 TSI | внешний | используется **только** для сцены заставки |
| `DESIGN (1).md` | Style-reference OpenSea | внешний | используется **только** для оболочки и плотности |

## Чего здесь не хватает

- `DESIGN (2).md` — style-reference Leonardo.ai. Исключён из проекта решением DEC-011.
- `spike.mjs` — сам скрипт замера данных. Отчёт есть, воспроизвести замер нечем.
- `catalog-snapshot.json` — снимок каталога из прогона 2. Единственный вход для проверки Q-19.
- `report.json` — полные данные замера, упомянуты в отчёте прогона 1.

## Именование

`DESIGN.md` и `DESIGN (1).md` различаются регистром и пробелом, а документы ссылаются на них как на `DESIGN(1)` и `DESIGN(2)`. На case-sensitive системе ссылка не разрешится. Переименование не выполнялось, чтобы не ломать существующие ссылки; проблема зафиксирована, а не решена.

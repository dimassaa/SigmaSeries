# data-spike — замер покрытия данных IMDb → TMDB

Одноразовый инструмент Фазы 1 (`DATA-SOURCES` §10). **Не часть продукта.** Отвечает на вопросы: сколько сериалов из топ-1000 сопоставляется, у скольких есть постер, фон без текста, ru-описание, возрастное ограничение и, главное, **даты серий до конца декабря**. Заодно проверяет «новинки» через TMDB и оценивает число запросов для полного импорта.

Скрипт без зависимостей, нужен Node.js 18+. Проверен на синтетических данных и имитации TMDB; **на настоящем API ещё не запускался** — поля сверены по документации, возможны мелкие правки.

## Подготовка

1. **Ключ TMDB.** Аккаунт на themoviedb.org → Settings → API → запросить ключ (некоммерческое использование). Берите **API Read Access Token**; подойдёт и обычный API Key.
2. **Датасеты IMDb.** Положите в папку `data/` два файла с https://datasets.imdbws.com/ : `title.basics.tsv.gz` и `title.ratings.tsv.gz`. Или запустите с `--download` — скрипт скачает сам. Файлы не распаковывайте. Только личное и некоммерческое использование.

## Запуск

PowerShell (Windows):
```powershell
$env:TMDB_TOKEN = "ваш_токен"
node spike.mjs --sample 60 --new 30 --until 2026-12-31
```
bash:
```bash
TMDB_TOKEN=ваш_токен node spike.mjs --sample 60 --new 30 --until 2026-12-31
```
С ключом v3 вместо токена: `TMDB_API_KEY`.

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `--dir` | `data` | Папка с файлами IMDb |
| `--out` | `spike-out` | Куда писать отчёт |
| `--top` | 1000 | Размер «самых популярных» |
| `--sample` | 60 | Сколько из топа проверять (плюс треть идущих сверху) |
| `--new` | 30 | Сколько новинок проверять |
| `--months` | 12 | Окно новинок, месяцев назад |
| `--until` | 2026-12-31 | Конец окна расписания |
| `--rps` | 10 | Запросов в секунду к TMDB; не поднимайте без нужды |
| `--download` | — | Скачать датасеты IMDb |

Порядок величин: 60 + 30 сериалов — несколько минут. Чтение `title.basics` — по потоку, десятки секунд.

## Что получить и прислать

Файл `spike-out/report.md` (полный JSON — `report.json`). Мне нужны целиком:
1. список «топ-сериалов выборки» — глазами проверим, нет ли «не сериалов»;
2. доли сопоставления, постеров, фонов без текста, описаний ru;
3. раздел «Расписание» и таблица по неделям;
4. блок «Новинки»;
5. оценка запросов и времени для полного импорта.

По цифрам решим: нужен ли TVmaze, как уточнить фильтры, достаточно ли целей `DATA-SOURCES` §7.

## Замечания

- Ключ и токен не коммитим. Папки `data/` и `spike-out/` — в `.gitignore`.
- TMDB может отвечать 429: скрипт ждёт и повторяет. Если 429 много, уменьшите `--rps`.
- «Идущий» = статус «Returning Series» или «в производстве». Даты берутся из последнего сезона.
- Фон «без текста» — изображение без указания языка; это эвристика.
